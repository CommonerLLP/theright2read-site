DDI-Codebook

One codebook per UDISE+ release year. Each is valid against the DDI-Codebook 2.5 schema, namespace ddi:codebook:2_5.

DDI nests the question inside the variable it produced, so a release year gets its own codebook. A variable carries the Ministry's release description as its label, the Data Capture Format question as qstnLit, the form's code list as catgry, and the rename history as verStmt.

Nine variables carry undocCod, which DDI defines as “values whose meaning is unknown”. Those are the codes the released column holds and no form defines.
