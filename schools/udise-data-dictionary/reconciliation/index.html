Year reconciliation

One file per release year. Each field carries three slots: what the Data Capture Format asked that year, what the Data Sharing Policy schema describes, and what the released column actually holds. Each file also carries the diff to the year before: columns added and dropped, confirmed renames, and questions whose printed wording moved between forms.

Two facts bound every read. The Ministry publishes one schema document per era, not per year: the four 2018-19 to 2021-22 downloads are byte-identical, and so are the four from 2022-23. And no national 2019-20 form is on disk — the portal's own DCF list skips the year, so that year's questions are verified from Delhi's rendition of the round, without national item numbers.
